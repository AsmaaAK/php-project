# Volunteer Matching Portal

> **A modern web application**
 for managing volunteers and events with an intelligent matching system based on **skills**, **location**, and **availability**.


## Overview
The Volunteer Matching Portal helps non-profit organizations efficiently manage volunteers and events.
It automatically matches volunteers with suitable events, providing an intuitive interface and responsive design.

## Features
- **Volunteer & Event Management** – Add, edit, delete and list volunteers/events.
- **Smart Matching Algorithm** – Matches based on skills, time, and location.
- **Real-time Notifications** – Instant feedback when a match occurs.
- **Responsive UI** – Built with Vue.js & TailwindCSS.
- **RESTful API** – Powered by PHP backend.

---

## Tech Stack
- **Frontend:** Vue.js 3, TailwindCSS 4
- **Backend:** PHP 8 
- **Database:** MySQL
- **Version Control:** Git & GitHub
